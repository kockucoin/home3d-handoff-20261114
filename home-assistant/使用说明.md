# Home Assistant 使用说明

安装方式：HA Core 2026.11.0，Python 3.14 虚拟环境（`.venv`），配置在 `config/`。
不会开机自启，不用时不占内存。

## 日常使用

- **启动**：在访达里双击 `启动HA.command`，就绪后会自动打开 http://localhost:8123
- **停止**：双击 `停止HA.command`
- 日志在 `ha.log`
- 第一次双击时如果 macOS 提示"无法打开"，右键选择"打开"即可

## 第一次启动后要做的事（需要你自己操作）

1. **创建管理员账号**：打开 http://localhost:8123，按向导设置用户名和密码，选择位置、时区（建议改成 Asia/Shanghai）
2. **接入米家**：设置 → 设备与服务 → 添加集成 → 搜索 **Xiaomi Home** → 登录小米账号，服务器区域选「中国大陆」→ 勾选要接入的设备
3. **（可选）HACS**：设置 → 设备与服务 → 添加集成 → 搜索 **HACS** → 按提示用 GitHub 账号授权。以后装小智插件（ha-mcp-for-xiaozhi）等社区插件就用它

## 已预装的自定义集成

| 集成 | 版本 | 位置 |
|---|---|---|
| Xiaomi Home（小米官方） | v0.5.0 | `config/custom_components/xiaomi_home` |
| HACS | 2.0.5 | `config/custom_components/hacs` |

## 限制

- Core 安装方式没有"加载项（Add-on）"商店，像 Whisper/Piper 这类要另外装
- 只在这台 Mac 开着、HA 启动时工作；定时开灯等自动化需要 HA 在运行

## 卸载

先运行 `停止HA.command`，然后删除整个 `home-assistant` 文件夹即可。

## WhatPlus 1916 Pro 唱片机

通过独立的蓝牙桥接程序接入（HA 本身仍不开蓝牙集成）。安装和限制见
`whatplus-bridge/README.md`；HA 配置在 `config/packages/whatplus.yaml`，需要在 `secrets.yaml` 里加 `whatplus_*` 五项。
