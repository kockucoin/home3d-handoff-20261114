# 天气 + 情绪灯光 接入指南（自己动手版）

同目录文件：`天气情绪灯光.yaml`（自动化配置，复制用）。
Home Assistant 地址：电脑 `http://localhost:8123`，手机 `http://192.168.10.34:8123`。

---

## 第 1 步：改对位置和时区（必须先做）

现在 HA 的时区是 `America/Los_Angeles`、位置也不在国内（安装时自动用了 Mac 的设置）。
不改的话：天气会查成美国的，3D 页面「白天/夜晚」也会按洛杉矶的日出日落切换。

设置 → **系统（System）** → **常规（General）**
- **时区**：`Asia/Shanghai`
- **位置**：地图上把定位点拖到家附近（大致即可）
- 点「保存」

---

## 第 2 步：添加天气（Met.no，免费、不用密钥）

设置 → **设备与服务** → 右下角 **添加集成** → 搜 **Met.no**（Meteorologisk institutt）→ 直接提交（默认用第 1 步的位置）。

**确认实体名**：开发者工具 → **状态** → 搜 `weather.`
- 一般是 `weather.forecast_home`。
- 如果不是（比如 `weather.forecast_wo_jia`），后面两处要改成你的名字：
  - `天气情绪灯光.yaml` 里全文替换 `weather.forecast_home`
  - 3D 卡片配置里加一行 `weather: weather.你的名字`（见第 3 步）

---

## 第 3 步：3D 页面显示天气 + 轻点开灯按天气配光

打开 `config/home3d-dashboard.yaml`，在 `type: custom:home3d-card` 下面加一行 `mood_by_weather: true`：

```yaml
      - type: custom:home3d-card
        mood_by_weather: true            # 轻点开灯时按天气/昼夜自动选亮度色温
        # weather: weather.forecast_home # 天气实体名不是默认值时才需要写
        entities:
          ...
```

保存后，手机/电脑上**下拉刷新**「3D 中控」：
- 顶栏会出现天气图标和气温（例如 `☁️ 18°`）。
- 在 3D 里**轻点**开灯 → 按天气配光；**按住**选「明亮/阅读/温馨/夜灯」预设 → 按你选的来，不会被覆盖。

---

## 第 4 步：自动化（米家/小爱开灯也按天气、日落自动温馨）

1. 用文本编辑器打开 `config/automations.yaml`
   - 现在内容是 `[]` → **整个替换**成 `天气情绪灯光.yaml` 的内容
   - 如果你以后已经有别的自动化 → 把 `天气情绪灯光.yaml` 里 `- id:` 开头的几段**追加**到末尾（不要再带 `[]`）
2. 开发者工具 → **YAML** → 点「**检查配置**」，显示「配置有效」后
3. 同一页点「**自动化**」那一项的「重新加载」
4. 设置 → **自动化与场景**，应该能看到两条「情绪灯光｜…」

包含的规则：

| 编号 | 名称 | 什么时候 | 做什么 |
|---|---|---|---|
| ① | 米家/小爱/开关开灯时按天气配光 | 用 HA 以外的方式开灯 | 按下表配光（在 3D 页面里开的灯不受影响） |
| ② | 日落后客厅自动「温馨」 | 日落前 15 分钟，客厅灯笼关着时 | 开到 45% · 2900K |
| ③ | 阴雨天白天客厅补光 | 默认**不启用**（文件里已注释） | 买了人体/人在传感器后再启用 |

配光规则（3D 轻点开灯和自动化 ① 共用）：

| 情况 | 亮度 | 色温 |
|---|---|---|
| 夜里（太阳落山后） | 30% | 2700K |
| 白天 · 阴 / 雨 / 雪 / 雾 | 65% | 3000K |
| 白天 · 晴朗 | 85% | 4300K |
| 白天气温 ≥ 30°C | 同上 | 再 +600K（偏冷白，看着凉快） |
| 白天气温 ≤ 10°C | 同上 | 再 −300K（偏暖黄，看着暖和） |

想改数值：改 `天气情绪灯光.yaml` 里 `bri` / `kelvin` 两行，以及 `3D模型/app/card.js` 里的 `moodFor()`（改完运行 `node build.mjs`），两边保持一致。

---

## 排错

| 现象 | 原因 / 办法 |
|---|---|
| 顶栏没出现天气 | 天气实体名不是 `weather.forecast_home` → 卡片配置加 `weather:`；或还没下拉刷新 |
| 自动化重新加载报错 | 多半是缩进或 `[]` 没删；用「检查配置」看具体行号 |
| 米家开灯后亮度被改了 | 这就是自动化 ① 的效果；不想要就在「自动化与场景」里把它关掉 |
| 白天/夜晚切换时间不对 | 第 1 步的时区或位置没改对 |
| 灯不响应 | 米家里看灯是否在线（小爱音箱的蓝牙 Mesh 网关要开着）；HA 里重新加载 Xiaomi Home 集成 |
