# 我家 3D 户型模型

根据 `../room.jpg` 户型图的毫米尺寸和 5 张房间照片生成。层高按 2.7 米估算。

## 文件
| 文件 | 用途 |
|---|---|
| `home.obj` + `home.mtl` | 3D 模型，给 Home Assistant 的 Floor3D Card 用（单位：厘米） |
| `preview.html` | 浏览器预览，可旋转、点灯具或列表开关灯、切换白天/夜间、矮墙剖切看室内 |
| `build.mjs` | 生成脚本。改尺寸/家具后运行 `node build.mjs` 重新生成 |

## 放进 Home Assistant
1. 把 `home.obj`、`home.mtl` 复制到 HA 的 `config/www/home/`
2. HACS 安装 Floor3D Card
3. 仪表盘添加卡片（字段以 Floor3D 官方文档为准，实体名换成你自己的）：

```yaml
type: custom:floor3d-card
path: /local/home/
objfile: home.obj
mtlfile: home.mtl
entities:
  - entity: light.living_room
    object_id: living_ceiling_light
    type3d: light
    light:
      lumens: 800
  - entity: light.dining
    object_id: dining_pendant
    type3d: light
    light:
      lumens: 600
  - entity: climate.living_ac
    object_id: living_ac
    type3d: color
    colorcondition:
      - color: '#4fb3ff'
        state: cool
```

## 已知的近似之处
- 门窗位置、各房门开口按户型图像素估算，误差约 ±20cm

- 层高、窗台高度为常见值，未实测
