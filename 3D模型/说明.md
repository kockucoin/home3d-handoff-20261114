# 我家 3D 户型模型

根据 `../room.jpg` 户型图的毫米尺寸和 5 张房间照片生成。层高按 2.7 米估算。

## 文件
| 文件 | 用途 |
|---|---|
| `home.obj` + `home.mtl` | 3D 模型，给 Home Assistant 的 Floor3D Card 用（单位：厘米） |
| `preview.html` | **3D 中控页（单文件）**，双击即可打开（需联网加载 three.js）。可旋转/缩放、双击房间放大、点图标弹出控制卡片、场景按钮、白天/夜晚、矮墙 |
| `app/home3d.js` | 3D 中控页的全部代码：精细家具/灯具（代码生成，无需下载模型）、按房间限定的灯光阴影、图标与控制卡片 |
| `app/index.html` + `app/house.json` | 同一个页面的拆分版，放进 HA 的 `www/` 或任何 http 服务里用 |
| `build.mjs` | 生成脚本：户型尺寸、家具布局（`layout`）、灯具、设备都在这里。改完运行 `node build.mjs`，会重新生成 OBJ、house.json 和 preview.html |

## 放进 Home Assistant
1. 把 `home.obj`、`home.mtl` 复制到 HA 的 `config/www/home/`
2. HACS 安装 Floor3D Card
3. 仪表盘添加卡片（字段以 Floor3D 官方文档为准，实体名换成你自己的）：

```yaml
type: custom:floor3d-card
path: /local/home/
objfile: home.obj
mtlfile: home.mtl
entities:
  - entity: light.living_room
    object_id: living_ceiling_light
    type3d: light
    light:
      lumens: 800
  - entity: light.dining
    object_id: dining_pendant
    type3d: light
    light:
      lumens: 600
  - entity: climate.living_ac
    object_id: living_ac
    type3d: color
    colorcondition:
      - color: '#4fb3ff'
        state: cool
```

## 3D 中控页（2026-11-14）
参考小红书「把我家装进 iPad，点哪里就亮哪里」视频的效果，做成可旋转版本：
- 默认近俯视的总览（竖屏北在上，横屏从东侧看），拖动旋转、双指缩放，双击房间飞进去
- 每盏灯有图标，点图标弹出卡片：开关 / 亮度 / 色温；罗马帘、卷帘有开合滑块；空调有温度和模式；电视可开关
- 直接点 3D 里的灯具 = 快速开关
- 场景按钮：全开、全关、观影（落地灯+蘑菇灯 30%、电视开、客厅帘关）、晚安（只留卧室B 15% 暖光）
- 夜晚模式下灯光被墙挡住，只照亮所在房间；"矮墙"按钮把墙压到 1.2 米看全屋（挡光仍按真实墙高）
- 白天/夜晚默认按时间自动切换（7:00–18:00 为白天），按钮可手动切换
- 现在是**模拟模式**；接 HA 时用 `createHome3D(容器, 数据, { onCommand })` 发命令，HA 状态变化时调用 `setState(id, {...})`
- 按 2026-11-14 新照片更新：客厅纸灯笼吊灯、白色罗马帘、餐厅布罩吊灯 + 蘑菇台灯、卧室B编织吊灯与飘窗卷帘、电视柜蓝白圆点门板、两个坐垫
- 已知：矮墙模式下墙面高处的空调、吊柜会悬空显示；家具尺寸为估算
